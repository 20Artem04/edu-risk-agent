# Чек-лист публикации репозитория

1. Заполнить титульный лист отчёта и первый слайд.
2. Проверить адрес репозитория `https://github.com/20Artem04/edu-risk-agent` в README.
3. Запустить `python scripts/run_pipeline.py`.
4. Запустить `python scripts/evaluate_agent.py` и `pytest`.
5. Проверить `streamlit run app.py` для трёх ролей.
6. Убедиться, что `.env`, ключи и реальные персональные данные отсутствуют.
7. Создать публичный репозиторий и отправить ветку `main`.
8. На чистой машине выполнить команды из раздела «Быстрый запуск».
9. Добавить URL репозитория в отчёт/систему сдачи.
10. При необходимости создать GitHub Release и прикрепить архив, DOCX и PPTX.
