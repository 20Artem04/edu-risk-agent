# Руководство пользователя

## Роли

- **Студент** видит только собственную карточку и общую информацию о модели.
- **Преподаватель** видит агрегаты групп и приоритетный список для педагогической поддержки.
- **Деканат** дополнительно видит технический журнал использования.

Переключатель роли в учебном прототипе демонстрирует RBAC, но не заменяет настоящую аутентификацию.

## Чат агента

Примеры запросов:

- `Покажи общую сводку`;
- `Какой риск у STU0001?`;
- `Сводка по группе ПИ-401`;
- `Покажи топ 5 студентов с высоким риском`;
- `Какие дисциплины самые сложные?`;
- `Какое качество модели?`.

Числа извлекаются параметризованными SQL-инструментами. Если Ollama включена, языковая модель только переформулирует проверенный черновик; если нет — интерфейс полностью работает в шаблонном режиме.

## Карточка студента

Шкала показывает модельную вероятность наличия хотя бы одной неудовлетворительной итоговой оценки. Уровни дашборда:

- низкий: менее 35%;
- средний: 35–64,9%;
- высокий: 65% и выше.

Порог бинарной модели, выбранный на validation, равен 0,44 и может отличаться от визуальных уровней приоритета. Факторы — приближённое локальное объяснение, а не причинный вывод.

## Правильная интерпретация

1. Проверить актуальность посещаемости, LMS и оценок.
2. Обсудить ситуацию со студентом.
3. Предложить поддержку и согласовать конкретное действие.
4. Повторить оценку на следующей контрольной точке.

Нельзя автоматически назначать санкции, отчислять, выставлять оценки или делать психологические/медицинские выводы.

## Дашборд

Фильтр группы применяется к распределению и карте индикаторов. Наведение на точку показывает ID, ФИО, группу и риск. Приоритетный список доступен только преподавателю и деканату.

## Включение локальной LLM

```bash
ollama pull qwen2.5:3b
# Linux/macOS
export LLM_PROVIDER=ollama
export OLLAMA_MODEL=qwen2.5:3b
streamlit run app.py
```

На Windows PowerShell используйте `$env:LLM_PROVIDER="ollama"`. Если Ollama остановлена, агент автоматически продолжает работу в безопасном шаблонном режиме.
