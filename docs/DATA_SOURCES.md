# Источники данных и происхождение

Все записи проекта **синтетические** и генерируются `src/generate_data.py` при фиксированном `seed=42`. ФИО составлены случайным сочетанием распространённых имён и фамилий и не относятся к реальным людям.

## Источник 1 — условная система деканата

| Файл | Формат | Гранулярность | Основные поля |
|---|---|---|---|
| `dean_students.csv` | CSV UTF-8 BOM | студент | ID, ФИО, группа, исторический GPA, вступительный балл |
| `dean_courses.csv` | CSV UTF-8 BOM | дисциплина | код, название, кредиты |
| `dean_grades.csv` | CSV UTF-8 BOM | студент × дисциплина | промежуточный балл, задания, итог, число попыток |

Имитация реальной выгрузки включает разные написания групп и категорий пола, пропуски, аномальный возраст/балл, дубликаты карточек и старые версии ведомости.

## Источник 2 — условная LMS

Файл `lms_events.jsonl`: одно событие на строку. Типы событий: вход, просмотр ресурса, попытка теста, отправка задания, сообщение форума. Присутствуют повторные `event_id`, отрицательные и пропущенные длительности.

## Источник 3 — условная система контроля доступа

Файл `access_attendance.csv`, разделитель `;`: отметка студента на занятии по дисциплине. Статусы поступают на русском и английском, числами и знаками. Добавлены дубликаты и неизвестные значения.

Генератор и сформированные им данные распространяются в составе проекта по MIT License. Набор предназначен только для обучения и демонстрации. Статистические результаты на нём нельзя переносить на реальный вуз.

## Воспроизводимость

```bash
python -m src.generate_data --students 420 --seed 42
```

Метаданные запуска и число строк записываются в `data/raw/generation_metadata.json`. После ETL происхождение и действия очистки фиксируются в `data_quality_log` и `data/processed/data_quality_log.csv`.
