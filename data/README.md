# Каталог данных

- `raw/` — пять синтетических выгрузок из трёх условных систем и метаданные генерации;
- `processed/` — модельный датасет, словарь признаков, разбиение, тестовые прогнозы и сводки;
- `education.db` — готовая SQLite-база демонстрационного приложения.

Все данные синтетические. Чтобы пересоздать каталог, запустите `python scripts/run_pipeline.py`. Не заменяйте их реальными персональными данными без правового основания, мер защиты и обновления `.gitignore`.
